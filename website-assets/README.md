# Baekho website assets

Everything used by the website, in one folder. Open **asset-index.html** for a visual catalogue of all 297 files (thumbnail, size, where it is used).

| Folder | What is inside |
|---|---|
| 01-logo-and-mascots | Baekho logo + all program mascots. `original-fullsize-png` (transparent) and `web-optimised-webp`. `not-used-yet` holds extra mascots. |
| 02-photos | The 4 real photos + Open Dojo poster: originals and web WebP. `not-used-yet` holds extra posters/banners from baekho.my. |
| 03-framed-images | **Every photo exactly as framed on the site** (organic blob masks, arch, rounded, curved-bottom cards, cream borders), as transparent PNG + WebP. |
| 04-vector-art | SVGs: hero dotted ring, section waves (3 shapes x 7 colours), background blobs (3 shapes x 6 colours), frame/mask shapes, stickers, curves, step blobs, ticks, toggles, menu buttons, palette, background gradients. |
| 05-icons | Every icon (benefits, values, tracks, NX4T) plain and inside its blob frame; WhatsApp / Instagram / Facebook / phone / mail / pin in blue, white, ink. |
| 06-container-shapes | Editable SVG outlines of every container: cards, buttons, chips, pills, inputs, notice, badges, progress bar, accordion row. |
| 07-ui-components | Transparent PNG renders (2x) of the real components from the live pages: cards, stickers, buttons, price cards, FAQ, trial wizard, header, footer, NX4T packages. |
| 08-reference-screenshots | Home sections + full-page desktop (1440) and mobile (390) screenshots of all 8 pages. |

## Photo credits / rights
Logo, mascots and photos are Baekho's own materials taken from baekho.my. Fonts: Bricolage Grotesque and DM Sans (Google Fonts, open licence).

## Design values used for the shapes
- Card radius 36px; benefit cards 36/36/36/8 (odd) and 36/36/8/36 (even); accordion rows 22px; inputs 14px; pills fully rounded.
- Photo masks (CSS border-radius): mask-a `58% 42% 48% 52% / 46% 56% 44% 54%`, mask-b `44% 56% 38% 62% / 58% 40% 60% 42%`, mask-c `70% 30% 60% 40% / 40% 60% 40% 60%`, arch `999px 999px 36px 36px`.
- Shadows: cards `0 18px 40px -18px rgba(10,27,51,.35)`; buttons `0 8px 0 -2px rgba(10,27,51,.22)`.
- Colours: see 04-vector-art/colour-palette.svg.
